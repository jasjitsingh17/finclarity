## Screenshot rules

- Use the same portfolio throughout.
- Avoid screenshots containing broken/empty API states.
- Do not show localhost browser chrome if you can crop cleanly.
- Keep typography large enough for LinkedIn/GitHub viewing.
- Do not fabricate market data.
- Prefer “latest available” wording to “real-time.”
- Avoid showing personally identifying local files or usernames.
